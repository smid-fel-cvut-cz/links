# Links

Curated indexes of **publicly available datasets for machine condition monitoring (MCM) and non-destructive testing (NDT)** — vibration, acoustic, current and other signals, images, video, and multimodal sensor data. All dataset URLs were verified live in October 2026.

| [`machine-condition-monitoring-2d-datasets.md`](machine-condition-monitoring-2d-datasets.md) | **Part 2 — 2D images & video.** X-ray radiography, optical surface-defect inspection, infrared thermography and video datasets for visual/automated NDT and anomaly detection. |
| [`machine-condition-monitoring-multimodal-datasets.md`](machine-condition-monitoring-multimodal-datasets.md) | **Part 3 — Multimodal.** Datasets combining two or more sensor families per machine/inspection event (e.g. vibration + current, vibration + acoustic, process + NDT, RGB + depth). |

## Notes

- Each dataset entry includes a short summary, the sensing modality, the target machine/component, the typical task, the license, and a download URL.
- Licenses vary: many are CC BY 4.0, but several (e.g. MVTec, Kolektor) are **non-commercial** — check per entry before redistribution or commercial use.
- Most datasets request a specific citation; the required reference is named in each entry.
